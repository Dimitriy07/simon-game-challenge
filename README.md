# Simon Game Challenge 🎮

## Introduction 🕹️
The **Simon Game Challenge** is a web-based memory game where players must replicate an increasingly complex sequence of colors and sounds. This project demonstrates the use of **HTML, CSS, JavaScript, and jQuery** to create an interactive game.

## Features ✨
- Interactive UI with color buttons
- Sequence-based gameplay
- Keyboard event listeners to start the game
- Visual and audio feedback for player interactions
- Game over logic with restart functionality

## Technologies Used 🛠️
- HTML5
- CSS3
- JavaScript (ES6)
- jQuery

## How to Play 🚀
1. **Start the Game**: Press any key to begin.
2. **Watch the Sequence**: The game will flash a colored button.
3. **Repeat the Sequence**: Click the buttons in the correct order.
4. **Increase Difficulty**: The sequence gets longer with each round.
5. **Game Over**: If you make a mistake, the game resets.

## Installation & Setup 🏗️
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/simon-game.git
   ```
2. Navigate to the project folder:
   ```bash
   cd simon-game
   ```
3. Open `index.html` in your browser to play!

## Code Explanation 💻
### **HTML (index.html)**
- Defines the game structure.
- Includes buttons representing colors.
- Links external **CSS** and **JavaScript** files.

### **CSS (styles.css)**
- Styles the game elements.
- Provides color effects and animations.

### **JavaScript (game.js)**
- Uses **jQuery** for event handling.
- Generates random sequences.
- Manages player input.
- Implements game logic.
